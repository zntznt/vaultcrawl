# Tests that fail today, so CI can be green without pretending they pass.
#
# `tests/conftest.py` marks every node listed here `xfail(strict=True)`. Two consequences
# worth understanding before editing this file:
#
#   * A listed test that starts PASSING fails the build. That is deliberate. It means this
#     list cannot quietly become a lie about what is broken: fix the bug, delete the line,
#     same commit.
#   * An entry that matches no collected test is a collection ERROR, not a warning. A typo
#     or a renamed test would otherwise silently widen the hole.
#
# So this file only ever shrinks. Every line is a bug with a name.
#
# These are not new. They fail identically on every commit checked back to before the
# assessment work began, and they are mostly not stale expectations: several are authored
# features wired to nothing, the same class as the deploy crash and the unreachable
# dialogue tree. See guidance/PROJECT_ASSESSMENT.md.
#
# Measured on Python 3.11.15 and cross-checked at module level on 3.12.3.
